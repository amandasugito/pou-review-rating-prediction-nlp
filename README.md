# 🎮 Pou Game Review Rating Prediction Using NLP

## 📌 Project Overview

This project applies Natural Language Processing (NLP) and machine learning to analyze and predict star ratings from Pou mobile game reviews collected from Google Play Store.

The workflow begins with web scraping using the `google-play-scraper` library to collect up to 2,000 English-language reviews from the US Google Play Store. The collected data is then explored, preprocessed, and used to develop and compare multiple text classification models, including Logistic Regression, Random Forest, and LSTM.

The project also investigates class imbalance and evaluates techniques such as SMOTE and class weighting to improve the recognition of underrepresented rating categories.

## 🎯 Project Objectives

- Collect and analyze 2,000 English-language game reviews.
- Explore review patterns and word distributions across rating categories.
- Preprocess text while preserving meaningful language features.
- Compare TF-IDF and Word2Vec text representations.
- Build Logistic Regression and Random Forest classification models.
- Develop an LSTM model for rating prediction.
- Evaluate the impact of SMOTE and class weighting on imbalanced ratings.

## 📂 Dataset

The project uses 2,000 reviews of the Pou mobile game, collected using `google-play-scraper`.

Each record contains two columns:

| Column | Description |
|---|---|
| `review` | Text of the user review |
| `rating` | User rating from 1 to 5 |

### 📊 Rating Distribution

| Rating | Number of Reviews |
|---|---:|
| 1 star | 246 |
| 2 stars | 44 |
| 3 stars | 66 |
| 4 stars | 157 |
| 5 stars | 1,487 |
| **Total** | **2,000** |

The dataset is highly imbalanced, with five-star reviews accounting for most observations.

## 🔎 Exploratory Data Analysis

The notebook explores:

- Missing values and data quality.
- Dominant words across rating categories.
- Non-standard words and text characteristics.
- Word clouds for different rating levels.
- The distribution of ratings and potential class imbalance.

## 🧹 Text Preprocessing

The text preprocessing pipeline includes:

- Converting text to lowercase.
- Expanding selected English contractions.
- Removing non-alphabetic characters.
- Tokenizing text.
- Removing English stopwords while preserving the word `not`.
- Applying lemmatization.
- Converting processed tokens back into text for vectorization.

## 🔤 Text Representation

### 1. 📐 TF-IDF

Term Frequency–Inverse Document Frequency (TF-IDF) represents text using weights that reflect the importance of words within documents and across the dataset.

The notebook uses `TfidfVectorizer` with a maximum of 5,000 features.

### 2. 🧩 Word2Vec

Word2Vec learns word representations from surrounding word contexts using a neural-network-based approach.

The notebook uses a vector size of 100, a context window of 5, and a minimum word count of 2. Review representations are generated by averaging the vectors of words present in each review.

## 🤖 Machine Learning Models

### 1. 📊 Logistic Regression

Logistic Regression is evaluated with both TF-IDF and Word2Vec representations. Hyperparameter tuning is performed using `GridSearchCV`.

### 2. 🌲 Random Forest

Random Forest is evaluated with both text representations. The notebook tunes the number of estimators and maximum tree depth.

## 🧠 Deep Learning Model

### 🔄 Long Short-Term Memory (LSTM)

The LSTM model uses tokenized and padded review sequences to learn sequential patterns in text.

The architecture includes:

- An embedding layer with 100-dimensional embeddings.
- An LSTM layer with 64 units.
- A softmax output layer for five rating classes.
- Adam optimization and sparse categorical cross-entropy loss.

The model is trained for 10 epochs with a batch size of 32.

## ⚖️ Handling Class Imbalance

The project explores two strategies:

### 1. 🔁 SMOTE

SMOTE generates synthetic samples for minority classes in the training data. It is applied to the TF-IDF and Word2Vec representations for machine learning experiments.

### 2. ⚖️ Class Weighting

Class weights are calculated using `compute_class_weight` and applied during LSTM training to increase the importance of minority-class errors.

## 📈 Evaluation and Findings

The notebook evaluates classification performance using:

- Accuracy
- Precision
- Recall
- F1-score
- Classification reports
- Confusion matrices

The notebook's conclusions report that:

- Logistic Regression with TF-IDF achieved the highest accuracy among the initial machine learning experiments, but performed poorly on minority ratings.
- SMOTE improved the recognition of some minority classes, although accuracy decreased.
- TF-IDF generally performed better than Word2Vec in the reported machine learning experiments.
- LSTM with class weighting was identified in the notebook's conclusion as the strongest model based on F1-score.

These findings highlight why accuracy alone can be misleading when rating distributions are highly imbalanced. The results should be interpreted alongside per-class metrics.
